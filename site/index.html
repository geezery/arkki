What it does

One library from a blank sheet to a signed file.

Arkki is Finnish for a sheet of paper. It covers the whole life of a PDF, and runs the same on Windows, Linux and macOS.

  • Create with a layout engine

    A tree of elements flows onto as many pages as it needs: mixed-style and justified text, lists, tables with repeated headers and column spans, rows, columns, keep-together, headers and footers with page numbers.

  • Open, edit and merge

    Stamp over existing pages, insert, remove, move and rotate them, merge files, extract pages, add bookmarks and attachments. The reader repairs damaged cross-references and extracts text.

  • Forms

    Text fields, check boxes, radio buttons, combo boxes and list boxes. Fill an existing form by its field names, create fields on new pages, and read the fields of any file. Filled fields get their own appearance, so they show in every viewer.

  • Encryption

    Writes AES-256 (PDF 2.0, revision 6) with user and owner passwords and permissions. Reads every standard security handler revision: RC4 40/128-bit, AES-128 and AES-256.

  • PAdES signatures

    The Arkki.Pdf.Signing package signs from PAdES B-B to B-LTA: invisible or drawn on the page, timestamped, with validation data and document timestamps for the long term. Each step is an incremental update, so earlier signatures stay valid. The verifier checks integrity, coverage, revocation and the certificate chain.

  • Barcodes

    Code 128, EAN-13 and QR code drawn as vector rectangles, in the flow or at an exact position. Other symbologies plug in through IBarcodeSymbology.

  • Fonts and images

    TrueType fonts are embedded as subsets of the glyphs used; OpenType CFF fonts are embedded whole. PNG with transparency and JPEG, stored in the cheapest lossless form and once per document.

  • An exact canvas

    When a form needs every mark in its place, draw directly: text, rotated text, opacity, barcodes and links at coordinates you give, in points or millimetres.

  • Robust against bad files

    A file that cannot be read fails with a clear exception, never a hang. The test suite mutates every sample file thousands of times and refuses streams that decode past 256 MB.

In code

Reads like the document it makes.

The samples below are taken from the README.

Create a document

Build a tree of layout elements and render it. It takes as many pages as it needs, and the header knows the page count.

  • Left, right, centred and justified text
  • Table headers repeat on each page
  • Paper sizes A0–A7, B, C, DL, Letter, Legal and any custom size
var doc = new PdfDocument();
doc.Info.Title = "Order 1187";
var fonts = new FontFamily(doc.AddFont(File.ReadAllBytes("Inter-Regular.ttf")),
                           doc.AddFont(File.ReadAllBytes("Inter-Bold.ttf")));
var body = new TextStyle(fonts, 10);

var table = new Table([new TableColumn(Len.Star()), new TableColumn(Len.Mm(30), HAlign.Right)])
    .SetHeader(body with { Bold = true }, "Item", "Amount");
table.AddRow(body, "Machining", "258,00");

new FlowDocument
{
    Header = page => new TextBlock($"Page {page.PageNumber} ({page.PageCount})", body, HAlign.Right),
    Content = new Column(
        new TextBlock("Order 1187", body with { Size = 18, Bold = true }),
        new ListBlock(body, ListMarker.Number).Add("Check the parts").Add("Book the time"),
        table) { Spacing = 8 },
}.RenderTo(doc);

using var file = File.Create("order.pdf");
doc.Save(file);              // or doc.ToArray()

Open, edit and merge

Open a file someone else made, draw over it, rearrange its pages and save. Merging stores identical objects once.

var doc = PdfDocument.Open(File.ReadAllBytes("contract.pdf"));

// Stamp: draw over an existing page.
PdfCanvas c = doc.Pages[0].Canvas;
c.Save(); c.SetOpacity(0.2); c.TextRotated(font, 60, 150, 500, 45, "DRAFT"); c.Restore();

// Pages: insert, remove, move, rotate.
doc.RemovePageAt(3);
doc.MovePage(0, 2);
doc.Pages[1].Rotation = 90;

// Bookmarks and attachments.
doc.Outline.Add("Terms", doc.Pages[1]);
doc.Attach("order.xml", File.ReadAllBytes("order.xml"), "application/xml");

byte[] batch = PdfDocument.Merge(invoicePdfs).ToArray();
PdfDocument firstTwo = PdfDocument.ExtractPages(pdf, 0, 1);

Fill and create forms

Set values by field name, or put new fields on a page. Reading works on any file, whoever made it.

// Fill an existing form by its field names.
var doc = PdfDocument.Open(File.ReadAllBytes("application.pdf"));
doc.Form.SetValue("customer.name", "Maija Meikäläinen");
doc.Form.SetChecked("agree", true);
doc.Form.SetValue("delivery", "courier");          // a radio group
doc.Form.SetValues("extras", ["Gift wrap", "Insurance"]);

// Or create fields.
PdfPage page = doc.AddPage();
page.AddTextField("email", x: 50, y: 100, width: 200, height: 18);
page.AddCheckBox("newsletter", x: 50, y: 130, size: 12);
page.AddRadioButton("plan", "basic", x: 50, y: 160, size: 12, selected: true);
page.AddRadioButton("plan", "pro", x: 50, y: 180, size: 12);
page.AddComboBox("language", x: 50, y: 210, width: 120, height: 18,
    ["Suomi", "Svenska", "English"], value: "Suomi");
page.AddListBox("days", x: 50, y: 240, width: 120, height: 40,
    ["Mon", "Tue", "Wed"], multiSelect: true);

// Read the fields of any file.
foreach (PdfFormField f in PdfReader.Open(pdf).GetFormFields())
    Console.WriteLine($"{f.Name} = {f.Value}");

Encrypt and sign

Encryption is one property. Signing lives in its own package, which adds only Microsoft's System.Security.Cryptography.Pkcs.

  • RSA and ECDSA keys, SHA-256/384/512
  • Visible signatures with text, a picture and your own font, in a new box or an existing signature field
  • Keys on a smart card, in an HSM or with a signing service through IExternalSigner
  • Certification signatures, timestamps, and long-term validation data (B-LT, B-LTA)
  • The verifier reports integrity, coverage, level, revocation and chain trust
doc.Encryption = new PdfEncryption(userPassword: "open", ownerPassword: "owner",
    permissions: PdfPermissions.Print | PdfPermissions.Copy);

X509Certificate2 cert = X509CertificateLoader.LoadPkcs12FromFile("signer.p12", password);
byte[] signed = PdfSigner.Sign(pdf, cert,
    new PdfSignatureOptions { Reason = "Approved", Location = "Helsinki" });

// Visible and timestamped (PAdES B-T): drawn on the page, with the time proved
// by an RFC 3161 authority.
var authority = new HttpTimestampClient(httpClient, new Uri("https://tsa.example.com"));
byte[] stamped = await PdfSigner.SignAsync(pdf, cert, new PdfSignatureOptions
{
    Appearance = new PdfSignatureAppearance { X = 50, Y = 700, Width = 220, Height = 60 },
    Timestamp = authority,
});

// Long-term: revocation data in the file (B-LT), then a document timestamp (B-LTA).
byte[] longTerm = await PdfSigner.AddValidationDataAsync(stamped,
    new HttpRevocationClient(httpClient), issuers);
byte[] archived = await PdfSigner.AddDocumentTimestampAsync(longTerm, authority);

foreach (PdfSignatureInfo s in PdfSignatureVerifier.Verify(archived, trustedRoots))
    Console.WriteLine($"{s.FieldName}: intact {s.IsIntact}, {s.Level}, {s.Revocation}, trusted {s.ChainTrusted}");
Performance and size

Fast enough to run per request.

Measured on a two-core cloud VM. Fonts are subset, images are embedded once, and merging stores identical objects once.

1.2s

A 50 000-row table lays out to 1 021 pages in about 1.2 seconds, and the file is 1.5 MB.

5ms

The three-page sample invoice renders in about 5 ms, at roughly 100 kB including the logo and two subset fonts.

Packages

Two packages, .NET 10.

PackageContentsDepends on
Arkki.Pdf Writer, layout engine, fonts, images, barcodes, reader, merging, page operations, stamping, forms, links, bookmarks, attachments, encryption Nothing
Arkki.Pdf.Signing PAdES digital signatures from B-B to B-LTA, visible or invisible, with a local or an external key, and their verification with revocation checking System.Security.Cryptography.Pkcs

Fonts and images are immutable and safe to share across threads. A PdfDocument or a PdfReader is used by one thread at a time; build documents in parallel freely. Arkki never looks for system fonts: you pass in the bytes.

Not included

What Arkki does not do.

Better to know before you start than after.

  • Tagged PDF and PDF/UA
  • PDF/A
  • Right-to-left and complex-script shaping (Arabic, Indic)
  • Rendering pages to images
  • SVG
  • CFF font subsetting (CFF fonts are embedded whole)
  • Signature policies (PAdES-EPES) and checks of certificate policies
  • RSA-PSS signatures from an external signer
  • Signing encrypted PDFs, and locking fields with a signature
  • Hyphenation dictionaries (plug in your own with IHyphenator)
